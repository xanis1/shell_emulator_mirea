# Эмулятор оболочки ОС

## 1. Общее описание
Эмулятор командной строки UNIX-подобной ОС. Поддерживает REPL (интерактивный режим ввода), считывание конфигурации при запуске и автоматическое выполнение стартового скрипта с перехватом ошибок. Выполнен 2 этап (вариант 30).

## 2. Описание всех функций и настроек
* Настройки конфигурации: скрипт принимает флаги `--vfs` (путь к ZIP-архиву) и `--script` (путь к стартовому скрипту).
* `run_script(script_path, config, state)`: выполняет команды из файла, прерывает работу при синтаксических ошибках или неверных командах.
* `cmd_conf_dump(config)`: выводит текущие параметры конфигурации.
* `cmd_ls(args)`: функция-заглушка для вывода команды ls.
* `cmd_cd(args)`: функция-заглушка для команды cd (обрабатывает ошибку неверного количества аргументов).

## 3. Команды для сборки проекта и запуска тестов
* Запуск эмулятора с аргументами: `python src/emulator.py --vfs archive.zip --script start.txt`
* Автоматическое тестирование (через bat-файлы): запуск `test_success.bat` (успешный скрипт) или `test_error.bat` (скрипт с ошибкой).
* Обычный запуск REPL: `run.bat`

## 4. Примеры использования
vfs:/ $ conf-dump
vfs_path=archive.zip
script_path=start.txt

vfs:/ $ ls -l
Вызвана команда: ls
Аргументы: ['-l']
